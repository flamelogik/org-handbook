# Logik Org Handbook

This is the owners' working manual for the [flamelogik](https://github.com/flamelogik) GitHub organization, the home of community projects from Logik, the Autodesk Flame user group.

If you're a contributor looking for how to get involved, head to the [contributing guide](https://github.com/flamelogik/.github/blob/main/CONTRIBUTING.md) instead.

| Document | Purpose |
|---|---|
| [MASTER_PLAN.md](MASTER_PLAN.md) | Phased setup plan leading to the late-October 2026 launch. It's a living checklist, so tick boxes as you go. |
| [OWNER_RUNBOOK.md](OWNER_RUNBOOK.md) | How to handle recurring owner jobs: approving proposals, adding maintainers, archiving, audits and reports. |
| [DECISIONS.md](DECISIONS.md) | Dated log of governance decisions and the reasons behind them. |
| [scripts/](scripts/) | GitHub CLI scripts used by the plan and the runbook. |

The contributor-facing policies (governance, contributing, code of conduct, repo standards) live in the [`.github` repo](https://github.com/flamelogik/.github), so every repo in the org inherits them.

## Changing this handbook

This repo is protected like every other community repo, so changes go through pull requests. Record any change to how the org is run in `DECISIONS.md` in the same PR.
